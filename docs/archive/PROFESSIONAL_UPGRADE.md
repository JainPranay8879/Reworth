# Professional Upgrade — ReWorth v2

## Product-level improvements

1. Multi-step assessment instead of a single long form.
2. Optional costs and explicit uncertainty handling.
3. Structured problem categories plus a natural-language description.
4. Separate functional and cosmetic condition.
5. Category-aware expected useful life.
6. Transparent multi-factor score.
7. Confidence level based on information quality.
8. Diagnosis Required state for insufficient information.
9. Result explanation with positive signals, cautions and next step.
10. Score-factor breakdown for transparency.
11. Better dashboard statistics and history presentation.
12. Human-friendly empty, validation and error states.
13. Backward-compatible SQLite migration for the previous project database.
14. Production-oriented README and testing documentation.

## Deliberate non-features

ReWorth does not claim to:

- identify the exact failed hardware component
- provide professional repair quotes
- guarantee repairability
- provide live market prices
- make purchasing or payment decisions
- use machine learning without a trained model/data pipeline

## Future AI enhancement

An optional AI assistant can convert free-text descriptions into structured problem information and ask follow-up questions. The final recommendation should continue to come from the transparent ReWorth engine.
